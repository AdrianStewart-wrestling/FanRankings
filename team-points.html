Advancement points 1 point per championship-bracket win, 0.5 per consolation-bracket win. No advancement point is awarded for winning a placement match itself (finals, 3rd, 5th, 7th) — those wins only add placement points. Since this calculator projects a finish rather than a full match path, advancement points shown for each finish use the typical minimum-win route to that result — the exact number can run higher if a wrestler takes a longer road through the bracket.
